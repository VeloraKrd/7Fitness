# 7F Fitness Club — сайт

Одностраничный сайт премиального фитнес-клуба **7F** (Краснодар).
Тёмный минимализм, крупная типографика, фоновое видео, анимации при скролле.

Стек: **React + Tailwind CSS + Framer Motion** (подключаются с CDN — сборка не требуется, сайт работает как есть).

---

## 📁 Структура

```
7f-fitness-club/
├─ index.html            ← главная страница (открывается в браузере)
├─ assets/
│  ├─ app.js             ← собранный код страницы
│  ├─ hero.mp4           ← фоновое видео первого экрана
│  ├─ favicon.svg        ← иконка сайта
│  └─ trainers/          ← сюда положить фото тренеров (см. файл внутри)
├─ src/
│  └─ app.jsx            ← исходный код (для правок текста/данных)
├─ .nojekyll             ← нужно для GitHub Pages
└─ README.md
```

## 🚀 Как опубликовать на GitHub Pages (бесплатно, откроется и с телефона)

1. Создайте репозиторий на GitHub, например `7f-fitness-club` (Public).
2. Загрузите в него все файлы из этой папки. Через сайт GitHub:
   **Add file → Upload files** → перетащите содержимое папки → **Commit changes**.
   Либо через терминал:
   ```bash
   git init
   git add .
   git commit -m "7F fitness club website"
   git branch -M main
   git remote add origin https://github.com/ВАШ-ЛОГИН/7f-fitness-club.git
   git push -u origin main
   ```
3. В репозитории откройте **Settings → Pages**.
4. В разделе **Build and deployment** → **Source** выберите **Deploy from a branch**,
   ветка **main**, папка **/ (root)** → **Save**.
5. Через 1–2 минуты сайт будет доступен по адресу:
   `https://ВАШ-ЛОГИН.github.io/7f-fitness-club/`
   Эту ссылку можно открыть с телефона и отправить кому угодно.

> Файл `.nojekyll` уже добавлен — он нужен, чтобы GitHub Pages корректно отдавал папку `assets/`.

### Альтернатива без гита — Netlify Drop
Зайдите на **app.netlify.com/drop** и перетащите туда эту папку целиком —
получите публичную ссылку за 10 секунд.

## ✏️ Как менять тексты, цены, контакты

Проще всего — в файле **`src/app.jsx`** (вверху массивы `TRAINERS`, `PLANS`, `NAV`
и константы `PHONE`, адрес — в компоненте `Footer`). После правок пересоберите:

```bash
npm install
npm run build      # соберёт src/app.jsx → assets/app.js
```

Если сборку ставить не хочется — те же тексты можно поправить прямо в
`assets/app.js` (код читаемый), затем просто обновить страницу.
